# כרטיס יום ההשקה — דף אחד, בשפה פשוטה

## ה-AI: **לא חוסם השקה.** בדקתי, וזו התשובה.

חשבתי שזה סיכון מספר אחת. **בדקתי בפועל וזה לא.**

| מה בדקתי | מה קרה |
|---|---|
| המפתח המשותף מדווח 429 | נכון — המודל הראשון בקצה המכסה |
| אז סטודנט תקוע? | **לא.** הסריקה הצליחה. יש שרשרת של ארבעה מודלים, והיא נפלה למודל זמין |
| ואם כל הארבעה ייגמרו? | **עדיין לא תקוע.** יש מסלול ידני שמסיים את האשף בלי שום AI — בדקתי אותו מקצה לקצה |

**מה שנשאר לך, ורק אם יתחשק:** להציץ במכסה ב-Google AI Studio. זה
ישפר את החוויה, אבל **גם בלי זה אף סטודנט לא ייתקע.**

## אם משהו נשבר ב-7.9 ואני לא כאן

**צעד ראשון תמיד — פריסה מחדש.** זה מה שהחזיר את האתר כשנפל:

```bash
cd "/Users/Ariel/קלוד קוד ניסוי 6 - אפליקציית פכמ על אמת/pakam-strategist" && npx -y vercel@48 --prod --yes
```

**לבדוק אם האתר חי:**
```bash
curl -s https://pakam-strategist.vercel.app/api/health
```
`"db":true` = המסד עונה · `"ok":true` = הכול תקין.

**אם המסד לא עונה** — הערך הקודם של `DATABASE_URL` שמור ב-`.env.local`
(פורט 5432). החזרה שלו ופריסה מחדש מגלגלת את השינוי של היום אחורה.
