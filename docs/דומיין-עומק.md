# מחקר-דומיין פכ"מ — עובדות לגל הפיצ'רים הבא

## אנגלית + אמירם (#18) — **קריטי, דדליין חוסם**
- פכ"מ דורש **2 קורסי-תוכן באנגלית** (≥2 ש״ס כ"א, נספרים ב-150) — **בלי קשר לאמירם**, גם פטור חייב.
- בנפרד: **קורסי-רמה** (0–4) שלא נספרים ל-150. כמה — לפי האמירם.
- סולם אמירם 50–150: **פטור 134+** · מתקדמים ב׳ 120–133 (קורס-רמה 1) · מתקדמים א׳ 100–119 (2) · בסיסי 85–99 (3) · טרום-בסיסי ≤84.
- **133 = מתקדמים ב׳, לא פטור** (חסרה נקודה אחת ל-134). חייב קורס-רמה 1 + 2 קורסי-תוכן.
- **דדליין חוסם**: חייב להגיע לפטור עד **סוף שנה א׳ סמסטר ב׳** — אחרת הלימודים נעצרים (PKM-022).
- ציון-מעבר אנגלית במדעי-הרוח = **70** (לא 60). הציון נשמר ב-`user.amiramScore`, נחשף כ-`amirantScore`.
- **פיצ'ר**: כרטיס "סטטוס אנגלית" בדשבורד — רמת-אמירם + 2 קורסי-תוכן + אזהרת-דדליין. המלצה: 120–133 = צהוב-אקשני.

## בחירה + קצב + יעד-מותאם-מילואים (#16,#17) — ✅ **מומש ב"המצב שלי"**
- 150 = **103 חובה** (כולל סמינר-פכ"מ; בקוד 101, חסר קורס 2-ש״ס עתידי) + **12 סמינרים** + **35 בחירה**.
- התמחות = 60 ש״ס בדיסציפלינה אחת. פטור-מילואים מצטבר עד 10 → ותיק צריך ~140 בפועל.
- מסך "המצב שלי" כבר מציג את כל הסלים + פטור-מילואים + נשאר-להשלים. ✓

## הצטיינות (#23) — דקאן/רקטור
- אין ספים בקוד; מ-web (מדעי-הרוח, **נכון לתשפ"ו, משתנה**): **דקאן ≈ ממוצע-שנתי-משוקלל 95** (top ~3%).
  **רקטור = אותו 95 + מן-המניין מלא בשני הסמסטרים**. **פר-שנה** (לא מצטבר). מינ' ~12 קורסים/30 ש״ס.
- בינארי >25% מהשעות השנתיות → פוסל הצטיינות. בינארי גם מוחרג מהממוצע.
- **פיצ'ר**: כרטיס "מרחק להצטיינות" — ממוצע-שנתי מול 95 (סף עם תיוג-שנה + לינק-חי, לא קשיח).

## אסטרטגיית בינארי למילואימניק (#24)
- מכסה: B=2/שנה · C=3/שנה · A=0 · G≈6 ש״ס · NONE=0. תקרת-תואר 5 קורסים. ≤10% מנ"ז התואר (~15).
- **מועמד טוב**: ציון-נמוך-עובר (בעיקר <75 כללי / <80 חובת-פכ"מ) בקורס **כבד** — מסיר גרר-ממוצע ושומר ש״ס.
- **לא לבינארי**: סמינרים, קורסי שער-המעבר (צריך מספרים), קריטי ל-MA/PhD, רישוי, וכל קורס שהצלחת בו.
- **תזמון**: ההחלטה **אחרי שהציון ידוע** (לכן הטוגל מופיע רק לקורס שהושלם עם ציון). בינארי = אין מועד-ב׳.
- **פיצ'ר**: badge "מועמד לבינארי" בכרטיס-קורס + המלצה במנוע (ציון-נמוך-עובר בקורס כבד, עם מכסה פנויה).

## בידינג (#25)
- מכרז (לא כל-הקודם-זוכה): מאגר-נקודות, **המציע-הגבוה זוכה**, **תזמון-ההקלדה לא משנה**.
- **2 מקצים**, **הנקודות מתאפסות בכל מקצה**. מינ' 5/קורס. **הרצאה+תרגיל = יחידה אחת**. שוויון בסף → הגרלה.
- **חפיפה (אפילו חלקית) מבטלת את הקודם** (הבקשה האחרונה מנצחת) — מלכודת-התכנון הגדולה.
- ביטול בין-מקצים מחזיר נקודות. תנאים (75/80, קדם) נבדקים **אחרי** הרישום. **פכ"מ פטור מדרישות-קדם** (רק עצה).
- **המכסה הכוללת לא מתפרסמת** → אסור להמציא תחזיות-נקודות.
- **פיצ'ר**: פאנל "מסביר-בידינג + צ'קליסט לפני מכרז" — מנגנון + בטיחות בלבד, אפס תחזיות.
