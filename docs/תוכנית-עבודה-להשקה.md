## 3 · התשתית שכבר בנויה — אל תבנה מחדש

### סיור צילומי המסך
`video/tour-lib.mjs` — נכנס כמשתמש אמיתי לפרודקשן, מצלם, ומודד בו-זמנית
מה שהעין לא תופסת.

```
openApp({width, height, mobile})   פותח דפדפן, אוסף שגיאות JS
login(p)                            מתחבר כ-test@pakamon.dev
shot(p, "שם")                       צילום ממוספר ל-video/shots/
measure(p)                          גלישה · טקסט חתוך · יעד <24px · משפט <12px
report(label, m, errors)            שורה אחת לכל מסך
```

**דוגמאות מוכנות:** `tour-01-onboarding.mjs` (האשף צעד-צעד) ·
`tour-02-app.mjs` (16 מסכים × כל הטאבים, `--mobile` לנייד) ·
`repro-L3.mjs`, `verify-L2.mjs` (שחזור באג ספציפי)

### חשבון הבדיקה
`test@pakamon.dev` / `test123456` — **כתיבה לפרודקשן מאושרת עליו בלבד.**
`npm run reset:test` מאפס אותו למצב אשף נקי. **להריץ לפני כל פרסונה.**

### פקודות

## 3א · אל תיגע — החלטות שכבר הוכרעו, וכל אחת נשמרת בדם

> **הסיכון הגדול ביותר במעבר בין סשנים** הוא לפתוח מחדש החלטה מנומקת
> ולשבור משהו שעובד. זה קרה כאן פעמיים ביום אחד. אם נראה לך שאחד מאלה
> שגוי — **תעצור ותשאל את אריאל.** אל תתקן לבד.

| מה | למה אסור לגעת |
|---|---|
| **היררכיית הכפתורים ב-`semester-summary.tsx`** — "סיום ושמירה" ראשי, "תכננו סמסטר נוסף" משני | הסדר ההפוך הוא **בדיוק** מה שגרם למחיקת התכנון של אריאל ב-2.9. ההערה בשורות 262-285 מתעדת את זה |
| **התנאי `isGenuinelyNew` ב-`dashboard-content.tsx:574`** | שינוי בו מריץ את האשף על משתמש קיים ו**כותב היסטוריה ריקה על האמיתית** — זה האיפוס שאריאל ראה, וה-5% שהוצגו לו |
| **שבעת אתרי גזירת קבוצת המילואים** (`regulation`, `plan`, `context-builder`, `binary-advisor`, `moed-benefit-banner`, `miluim-status-bar`, `use-qa-context`) | נבדק ב-4.9: מעבר לסמסטר הקרוב **מאבד** את הקבוצה הידועה מהסמסטר הקודם ונופל ל-fallback. שאלת-זכאויות, לא באג |
| **`getAcademicNow` ב-`semester-clock`, `time-focus`, `bidding-target`, `next-semester-reminder`, "השיעורים שלי היום"** | הם באמת שואלים מה הלוח עושה עכשיו. רק מי ששואל "לאיזה סמסטר אני נכנס" עבר ל-`getCurrentOrUpcomingSemester` |
| **`text-[10px]` ב-219 מקומות** | שפת העיצוב מתירה 10px לתוויות. הרצפה של 12px היא **למשפט** בלבד. החלפה גורפת הייתה מלכודת מתועדת |
| **אנגלית לא בממוצע התואר** · **רמה מוצהרת גוברת על אמירם** | אומת מול הבעלים |
| **אף פעם לא לנבא נקודות בידינג** | המכסה לא מתפרסמת, וההנחיות הרשמיות אומרות במפורש לא להסיק משנים קודמות |
| **חשבון הדמו קריאה-בלבד** · **כתיבה לפרודקשן רק ב-`test@pakamon.dev`** | הרשאה מפורשת של אריאל, מוגבלת לחשבון אחד |
| **הסיווג של "מבוא לכלכלה" בקטלוג** | ממתין להכרעת אריאל. **לא לשנות לבד** — אין מקור שסותר |
| **`ARAZIM_ENABLED` כבוי** | הסרה הפיכה בדגל; השורות במסד נשמרו בכוונה |
| **`/en/*` מפנה לעברית** | בכוונה. לא "לתקן" בלי אריאל |
