### 1. 🔑 מפתח-Gemini חינמי לכל משתמש (BYOK חינמי) + כלי-AI בסיסיים
**הרעיון (מאריאל, בהשראת אפליקציית HomeWise של חבר):** היום האפליקציה דורשת מפתח-Claude בתשלום — **חסם אמיתי**. הפתרון: לתמוך ב**מפתח-Gemini של גוגל, שיש לו שכבה חינמית**. כל סטודנט יוצר מפתח חינמי "ב-2 קליקים", מדביק אותו, ומיד מקבל גישה לכלי-ה-AI — **חינם, לכולם.** זה משנה את המשחק.

**מה ראיתי ב-HomeWise (מהצילומים של אריאל):**
- קטע "הפעלת בינה מלאכותית (BYOK)" עם שדה "מפתח Gemini API אישי", placeholder "הדביקו מפתח API כאן".
- טקסט-הסבר: "כדי להפעיל את הצ'אטבוט וסורק-הקבלות בחינם בחשבון האישי שלכם, הזינו את מפתח ה-Gemini שלכם."
- קישור בולט: **"אין לכם מפתח? לחצו כאן ליצירת מפתח Gemini חינמי ב-2 קליקים מגוגל".**
- כלים שזה מפעיל אצלם: צ'אטבוט + **סורק-קבלות** (סריקת-מסמך ב-AI).

**מה לבנות אצלנו (לפי מחקר+תכנון מעמיק לפני יישום):**
- **מנוע-AI דו-ספק:** להוסיף תמיכה ב-Gemini לצד Claude (היום יש רק Anthropic). הצפנת-המפתח כמו היום. ברירת-מחדל מוצעת = Gemini החינמי.
- **מסך-הגדרה ידידותי:** שדה-מפתח + מדריך-תמונות "איך יוצרים מפתח-Gemini חינמי ב-2 קליקים" (קישור ל-aistudio.google.com) + בדיקת-תקינות-מפתח.
- **כלי-AI שזה פותח (לתכנן ולבנות):**
  - **סורק-סילבוס:** מעלים סילבוס (PDF/תמונה/טקסט) → ה-AI מחלץ תאריכי-מבחנים, מטלות, ומשקלים → נכנס אוטומטית לכלי-המבחנים וללוח. (הערה #2 + ז5.)
  - **סורק-קובץ-סיכום-מבחנים/ציונים:** מעלים קובץ → מחלץ מה עשית + ציונים → ממלא את התיק-האקדמי. (הערה #2.)
  - **עוזר-תואר משודרג (פיצ׳ר-דגל חינמי):** שאלות-תשובות חכמות שמחוברות לתוכנית-האישית של כל אחד, עם "טאצ׳ים" של AI ברמה גבוהה. (הערה ז4.)
- **בטיחות:** הכול דרך מפתח-המשתמש-עצמו (אנחנו לא משלמים), קלט-מוגבל, אזהרות-ברורות. דמו = קריאה-בלבד.
