## שלב 0 · שתי הפעולות שלך · ~5 דקות · **הכי דחוף**

שתיהן דורשות אותך כי הן משתני־סביבה. אחרי כל אחת אני מאמת ומדווח.

### 0.1 · פורט המסד — הסיכון היחיד שכבר הפיל את האתר
ב-Vercel → Settings → Environment Variables → `DATABASE_URL`:
החלף `:5432` ל-`:6543`, הוסף `?pgbouncer=true` בסוף (אם כבר יש `?` —
`&pgbouncer=true`). ואז Redeploy.

**נבדק מראש** — `npx tsx scripts/probe-transaction-mode.ts` הריץ מולו את
כל דפוסי השאילתות של האפליקציה, כולל `$transaction` אינטראקטיבית
ושאילתות מקבילות. הכול עבר.

**מה אני עושה מיד אחרי:** `/api/health` ×6, עמוד הבית, התחברות, שמירת
תוכנית, ובדיקת עומס קצרה. אם משהו זז — **הגלגול לאחור הוא החזרת הערך
הקודם ופריסה**, שתי דקות.

### 0.2 · מכסת ה-AI — מה שישבור את החוויה הראשונה
[Google AI Studio](https://aistudio.google.com/apikey) → המכסה של המפתח
המשותף. כרגע הוא מחזיר **429**, ורק מהבדיקות שלי.

**למה זה קריטי דווקא בהשקה:** הצעד הראשון של סטודנט חדש הוא האשף, והאשף
סורק גיליון ציונים דרך Gemini. בלי מכסה, **החוויה הראשונה של כל משתמש
חדש נשברת**. כל סריקה עולה שלוש קריאות.

**מה אני עושה מיד אחרי:** מאמת שסריקה עוברת מקצה לקצה, ופותח את F14
(3010) ו-F15 (סילבוס) שחסומים בגלל זה.

## שלב 2 · המילואימניק — המשימה החדשה

> *"סטודנט שנה ג׳ שהוא מילואימניק, שהיה לו מילואים גם בשנה א׳ וגם בשנה ב׳"*

**מה שכבר מצאתי בקוד:**
`deriveCurrentGroup` מחפש שורת מילואים **לסמסטר הנוכחי**. אם אין — נופל
ל-`user.miluimGroup`. לסטודנט הזה אין שורה לשנה ג׳, ולכן הקבוצה הנוכחית
שלו נגזרת מה-fallback, לא משנים א׳–ב׳.

זה **נכון עקרונית** — הקבוצה נקבעת מחדש בכל סמסטר — והעמוד אומר זאת
במפורש: *"הקבוצה נקבעת בכל סמסטר מחדש, והזכאויות נצברות לכל התואר."*
יש כרטיס מצטבר נפרד לפטור ש״ס ולהמרות בינארי.

**מה שצריך לאמת חי, כי "כתוב" אינו "עובד":**
| | |
|---|---|
| א | הזכאויות משנים א׳–ב׳ **נשמרות** ולא מתאפסות בשנה ג׳ |
| ב | פטור הש״ס המצטבר מכבד את תקרת 10 ש״ס לתואר ולא מוכפל בשנים |
| ג | מכסת ההמרות הבינאריות משקפת את שתי השנים |
| ד | מועד ב׳ והבאנרים אומרים את האמת לסמסטר **הנוכחי** (בלי מילואים) |
| ה | המסך לא סותר את עצמו — "אין לך קבוצה עכשיו" לצד "יש לך זכאויות" |

**איך:** בונה את הפרסונה דרך הממשק (`הוסיפו סמסטר` בעמוד המילואים),
שנה א׳ וב׳ עם ימים שונים כדי לקבל קבוצות שונות, ואז קורא את
`/he/miluim`, `/he/record`, `/he/exam-planner` ו-`/he/graduation`.
**לא זריקה למסד** — ב-4.9 זריקה ישירה דילגה על `deriveGroupFromDays`
והולידה באג מדומה.
