3. **OAuth של גוגל (~40 דקות).** מסך ההתחברות עדיין מציג "…supabase.co". התיקון: OAuth-client בשם "פכמון" בקונסולת גוגל. אני מדריך צעד-צעד.
4. **דומיין** — ביקשת תזכורת. לא דחוף.
4ב. **בדיקת-חיבור יומן-גוגל (2 דקות).** הקוד אומת (ריענון-טוקן, סינון-קבוצות) אבל את ההענקה החיה אפשר לבדוק רק עם חשבון אמיתי: יומן → "סנכרון ליומן גוגל" → לוודא שהשיעורים מופיעים בגוגל. (הערה #14 שלך.)
