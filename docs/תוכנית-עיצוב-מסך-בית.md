## 1. האבחנה (מה שבור, מעוגן בקוד)

מסך-הבית הוא קומפוננטה אחת בת ~1,330 שורות
([`dashboard-content.tsx`](src/app/[locale]/(protected)/dashboard/dashboard-content.tsx))
שמערמת ~15 מקטעים בגלילה אנכית אחת. הבעיות הקונקרטיות:

1. **כפילות-סטטוס בוטה.**
   - התקדמות-ש״ס מופיעה ב-**שני** כרטיסים חופפים: `MyStatusHero` ו-`CreditOverviewWidget`
     (אותו `plan.getCredits`, שתי תצוגות).
   - הציון/ממוצע-בוגר מופיע ב-**ארבעה** מקומות: badge ב-Hero, `ScoreDisplay`, `ScoreBreakdown`,
     ושוב בתת-טאב Exams→Grades. הכותרת-המספרית מתחרה בעצמה.
2. **הסטטוס מוסתר מאחורי טאבים.** שלושה אזורים שלמים (לוח-מבחנים, יומן/מערכת-שעות, מטלות) חבויים
   ב-`DashboardTabs`, וה-Exams עצמו עם תת-טאבים (Schedule/Grades). הלו״ז-השבועי והמחשבון-ציונים
   שניהם **שתי קליקות עומק** ובלתי-נראים כברירת-מחדל.
3. **ארבעה משטחי-"לו״ז" שאף אחד לא סמכותי:** `TodaysClasses` (היום), `ExamCountdown` (3 מבחנים),
   תת-טאב Schedule (טבלת-מבחנים), טאב Calendar (`WeeklyTimetable`). חופפים וחיים במקומות שונים.
4. **#21 — השורש: התכנון מנותק מהלו״ז.** עריכת-התכנית ב-`/planner` (לוח-גרירה) **בלי שום מערכת-
   שעות**; הלו״ז השבועי חי רק ב-`/calendar`. כשסטודנט מוסיף/מזיז קורס הוא לא רואה את ההשפעה על
   הלו״ז — חייב לעבור דף כדי לראות התנגשויות.
5. **הדשבורד משכפל את ה-sidebar.** חלק עצום מהכרטיסים הם קישורי-ניווט חוזרים ליעדי-ה-sidebar
   (planner/graduation/regulations/record/settings/calendar). הדף עושה את עבודת-הסרגל פעם שנייה.
6. **לוגיקת חדש-מול-ותיק שזורה ב-JSX.** מקטעים מופיעים/נעלמים לפי תנאים חופפים (`isNewUser`,
   `hasEarned`, `hasFocusArea`, `hasGrades`, `currentYear>=2`...). הדף נראה אחרת כל יום — קשה
   לחיזוי, לבדיקה, ולעיצוב-מחדש.
7. **fan-out של queries.** ~6 queries ברמת-הדף + עוד בילדים (כולל `getUserPlan`/`getGraduationScore`/
   `getScheduleForSemester` כפולים). פוגע ב-first-paint ויוצר מצבי-טעינה לא-עקביים.

## 2. עקרונות-העל

1. **מקור-אחד לכל עובדה, מוצג פעם אחת.** להרוג כפילויות-קרדיט/ציון.
2. **מבט-על ("מעוף-ציפור") בראש הדף** שעונה "איפה אני בתואר" במבט אחד.
3. **שפת-התקדמות אחידה: 3-מצבים** לכל דרישה — *הושלם ✓ / בתכנון / לא-התחיל* — ש״ס-בתכנון שונים
   ויזואלית מ-ש״ס-שהושגו (הבר ה-4-מקטעי כבר עושה זאת; להרחיב לכל הסלים).
4. **#21: הלו״ז צמוד לעריכה.** מערכת-שעות חיה ליד פקדי-התכנון, שמתעדכנת בכל הוספה/הזזה.
5. **הדשבורד = סיכום + נקודת-זינוק, לא sidebar שני.** פעולה-אחת-הבאה מומלצת, לא ערימת-קישורים.

## 3. המבנה המוצע (מלמעלה למטה)

```
┌─────────────────────────────────────────────────────────────┐
│ HERO מאוחד "המצב שלי"  (ממזג MyStatusHero+CreditOverview+    │
│  ScoreDisplay+RegulationWidget לכרטיס אחד)                   │
│  • ש״ס: בר 4-מקטעי (הושג·בתכנון·פטור-מילואים·נותר) + מספר    │
│  • ציון/ממוצע-בוגר — מספר אחד יחיד                            │
│  • תאימות (compliant / N חריגות)                             │
│  • "הכי דחוף עכשיו" — פער אחד + פעולה אחת (ממנוע-ההמלצות)     │
│  • מצב מתחיל-באמצע: כש earned==0 & year>=2 → "תעד את העבר"    │
│    כמצב-ראשון בתוך ה-Hero (לא באנר מרחף)                      │
├──────────────────────────────┬──────────────────────────────┤
│ "השבוע שלי" (רצועה אחת)       │ סלי-דרישות (3-מצבים)          │
│  היום + מבחנים-קרובים          │  חובה·בחירה·סמינר·מיקוד·אנגלית │
│  toggle: היום / שבוע / מבחנים  │  כל סל = ✓/בתכנון/חסר + בר     │
├──────────────────────────────┴──────────────────────────────┤
│ המלצות חכמות (הרשימה הפעילה היחידה)                          │
└─────────────────────────────────────────────────────────────┘
```

**מה יוצא מהדשבורד (עובר ליעד הייעודי):**
- `ScoreBreakdown` + What-If המלא → `/graduation`.
- רשימת-החוקים המלאה (`DegreeGapWidget` המורחב) → `/regulations` (בדשבורד רק "הפער הבולט").
- טבלת-המבחנים המלאה → `/exam-planner` / `/exam` (בדשבורד רק רצועת "השבוע").

## 5. רולאאוט מדורג (כל שלב נשלח בנפרד, בר-בדיקה)

- ✅ **שלב A — לכבות כפילויות (בוצע 29.6, אומת חי דסקטופ+טלפון):** הוסרו מהדשבורד
  `CreditOverviewWidget` (קרדיט כפול), `ScoreDisplay` (ציון כפול), `RegulationWidget` (כרטיס-תאימות),
  `DegreeGapWidget` ("מה חסר"), ו-`ScoreBreakdown`+What-If. הקרדיט+הציון נשארים **פעם אחת** ב-Hero
  "המצב שלי"; הפירוט-המלא ב-/graduation, החוקים ב-/regulations. ~400 שורות הוסרו. הדף התקצר משמעותית.
  אומת: hero+המלצות נשארו, הכרטיסים-הכפולים נעלמו, אפס שגיאות, אפס גלישה בטלפון, 147 בדיקות + build נקי.
- ✅ **שלב B — רצועת "השבוע שלי" (בוצע 29.6, אומת חי):** `TodaysClasses` + `ExamCountdown` ממוסגרים
  כעת באזור אחד "השבוע שלי" מתחת ל-Hero, עם קישור "כל הבחינות" → `/exam`. סדר-האזורים תואם לציור.
- ✅ **שלב C — פירוק הטאבים (בוצע 29.6, אומת חי):** שורת-הטאבים (מבחנים/יומן/מטלות) הוסרה מהדשבורד.
  לוח-המבחנים (`ExamSchedule`, כולל תיקוני #33/#8) קיבל **עמוד אמיתי `/exam`** במקום redirect-לטאב;
  היומן ב-`/calendar`, המטלות ב-`/exam-planner` (כבר ב-sidebar). הסיור עודכן (צעד "tabs"→"השבוע שלך").
- 🟡 **#21 לו״ז-צמוד-לתכנון** — נבנה בנפרד (כבר ב-`/planner`, ראה קובץ-הבקרה). *לא חלק ממסך-הבית.*
- **שלב D (לא בוצע) — מכונת-מצבים לתצוגה:** לחלץ את לוגיקת חדש/ותיק מ-JSX; placeholders אמיתיים
  במקום `return null`.
- **שלב E (לא בוצע) — להרים queries משותפים** לרמת-הדף ולהעביר כ-props (פחות fan-out, first-paint מהיר).
