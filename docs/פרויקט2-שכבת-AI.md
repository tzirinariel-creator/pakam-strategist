> תוצר של מחקר מרובה-סוכנים (אודיט-קוד + 4 חוטי-מחקר-רשת + שיפוט). מקור-האמת לפרויקט-2.
> מלווה: [הערות-גל3.md](הערות-גל3.md) · [משימות-בקרה.md](משימות-בקרה.md) · [פרויקט1-זרימת-משתמש.md](פרויקט1-זרימת-משתמש.md).

## 🎯 החזון
להפוך את העוזר מ**עמוד `/mentor` בודד** ל**שכבה סביבתית** בכל האפליקציה — בלי לשבור את הכלל "תמיד חינם, תמיד נכון".
עוזר מרחף אחד (FAB, ממוסר ל-RTL) בכל מסך מוגן עונה "שאל/י כל דבר"; כל אובייקט (כרטיס-קורס, סמסטר, ווידג'ט-פער) יכול למסור את ההקשר שלו לעוזר בקליק.
מאחורי ה-UI **נתב-היברידי אחד:** הקוד הדטרמיניסטי הוא **הבעלים של האמת** (נקודות, דרישות-קדם, תקנון, פער-תואר — ממנועי `context-builder`/`degree-qa`/`recommendations` הקיימים), ורק ה**ניסוח/הנימוק** מסלים ל-Gemini, ורק לשאלות פתוחות ("למה/מה-אם/השווה") שהחוקים לא יכולים למנות.
ה-LLM **אף פעם לא מופעל אוטומטית**, התשובות במטמון לפי hash-התכנית, ומיצוי-מכסה/חוסר-מפתח **מתדרדר בשקיפות** לתשובה הדטרמיניסטית — לעולם לא לשגיאה. מפתח-Gemini חינמי מוצע **בדיוק ברגע-הצורך**, לא כשער-חובה.

## 🏗️ האדריכלות (reuse-first, 3 שכבות)
1. **תפר-הנתב** — מודול טהור חדש `src/lib/ai/answer-router.ts` עם כניסה אחת `answerQuestion(question, ctx) → {answer, source:'rules'|'cache'|'llm', needsKey}`. שכבות בסדר: Tier-0 = `answerDegreeQuestion()` הקיים (חינם, אפס-הזיה); Tier-1 = מטמון-סמנטי לפי {שאלה מנורמלת, hash-QAContext}; Tier-2 = ה-LLM דרך `/api/chat/stream` הקיים. מסלים ל-Tier-2 **רק** כשאין intent דטרמיניסטי בטוח **וגם** השאלה קשורה-לתואר, או שה-intent מתויג needs-reasoning.
2. **העוזר-המרחף** — `<FloatingAssistant/>` אחד ב-`(protected)/layout.tsx`: FAB ממוסר-RTL → פאנל בדסקטופ / bottom-sheet במובייל; `aria-live`, מלכודת-פוקוס, תג-מקור ("מהנתונים שלך" ירוק מול "תשובת AI"), צ'יפי-פתיחה של פכ"מ. אף פעם לא נפתח/יורה לבד. אובייקטים מציגים צ'יפ "שאל/י על זה" שפותח את העוזר עם ההקשר מצורף.
3. **המלצות-חכמות-יותר** — `buildRecommendations()` (8 חוקים דטרמיניסטיים) נשאר הבסיס-תמיד-פעיל, מוצג גם מעבר לדשבורד; פעולת-Gemini **אופציונלית** ("הסבר/תעדף") שהסטודנט לוחץ במפורש, דרך אותו נתיב-מטמון+מכסה.

**גראונדינג:** `mentor-prompt.ts` מזריק את המספרים המחושבים כבלוק "עובדות-מוסמכות — אל תחשב מחדש" (עולם-סגור, בלי הזיה). **מכסה:** `checkRateLimit()` כדלי-אסימונים לפני Gemini; מודל נעול ל-`gemini-2.5-flash-lite`; ב-429/חוסר-מפתח/timeout — נפילה לתשובה דטרמיניסטית + הערה רגועה. **אונבורדינג:** `<ConnectGeminiGuide/>` אחד לשימוש-חוזר.

## 🔑 הפעלת ה-AI לכולם — צעד אחד של אריאל (המפתח-המשותף)
העוזר כבר עובד בחינם (תשובות מהנתונים). כדי להדליק את שכבת-ה-AL לכל מי שאין לו מפתח אישי:
1. **יוצרים מפתח חינמי** ב-[aistudio.google.com/apikey](https://aistudio.google.com/apikey) → "Create API key".
2. **מוודאים שהחיוב כבוי** בפרויקט-Google של המפתח (Google Cloud → Billing → שלא מקושר חשבון-חיוב). כך פיזית אי-אפשר לגבות — מעבר למכסה מקבלים 429 בלבד.
3. **מגדירים ב-Vercel:** Project → Settings → Environment Variables → `GEMINI_SHARED_KEY` = המפתח → Production → Save → Redeploy.
4. זהו. האפליקציה מזהה את המשתנה (`hasApiKey.sharedAvailable`), והעוזר מסלים ל-AI לכולם, עם תקרות-הגנה (40/משתמש/יום, 800 גלובלי). מי שרוצה בלי הגבלה — מוסיף מפתח אישי בהגדרות.

> **אריאל לעולם לא צריך לתת לי את המפתח.** הוא מגדיר אותו ישירות ב-Vercel; אני רק כתבתי את הקוד שמשתמש בו.

## 🗂️ החלטות-בעלים (לאסוף לאריאל)
1. **מודל-מפתח:** BYOK-אמיתי (כל סטודנט מדביק מפתח-חינמי שלו = ~1,000 בקשות/יום משלו, מתרחב בחינם) מול מפתח-אפליקציה-משותף (תקרה גלובלית אחת). **המלצה: BYOK.** להחליט אם להציע "טעימה" חסומת-מכסה בלי מפתח.
2. **לספק מפתח-Gemini חינמי** (או חשבון-זבל) לאימות-הנתיב-החי הסופי (צעד 14).
3. **טעם-עיצוב:** FAB — מראה/מיקום (bottom-inline-start ל-RTL), ניסוח ("שאל/י את היועץ"?), האם מובייל = bottom-sheet מלא.
4. **אישור ניסוח-הפרטיות-הכן** + דיסקליימר-ייעוץ קבוע ("אינה החלטה רשמית — אמת/י מול השנתון").
5. **סקופ Cmd/Ctrl+K:** אילו שינויי-תכנית מותרים כפקודה בקליק.
6. **תקרה-יומית רכה** לפעולות-AI + מטמון ב-IndexedDB מול localStorage.
7. **אישור: אין שינוי-DB** — התכנון שומר מטמון+מונים בצד-לקוח כדי להישאר לא-חסום.
