### שלב 1 — לשכתב `src/components/ui/themed-loader.tsx`

החלף את כל תוכן הקובץ ב:

```tsx
"use client";

import { useLocale } from "next-intl";
import { PhilosopherKingIcon } from "@/components/ui/philosopher-king-icon";
import { cn } from "@/lib/utils";

interface ThemedLoaderProps {
  /**
   * `page` (ברירת-מחדל): מחליף עמוד שלם — מרכוז אנכי גבוה.
   * `inline`: מתחת ל-PageHeader קיים — בלי min-height, ריווח אנכי בלבד.
   */
  variant?: "page" | "inline";
  className?: string;
}

export function ThemedLoader({ variant = "page", className }: ThemedLoaderProps) {
  const locale = useLocale();
  const isHe = locale === "he";

  return (
    <div
      className={cn(
        "flex flex-col items-center justify-center gap-4 text-center",
        variant === "page" ? "min-h-[50vh]" : "py-16",
        className,
      )}
      role="status"
      aria-live="polite"
    >
      <div className="relative size-16">
        {/* טבעת אינדיגו מסתובבת — הקול של המוצר, לא אפור גנרי */}
        <div className="absolute inset-0 animate-spin rounded-full border-[3px] border-accent-brand/15 border-t-accent-brand [animation-duration:900ms]" />
        {/* הכתר במרכז — "חושב" (ספירת-הטוב נושמת) בזמן הטעינה */}
        <div className="absolute inset-0 flex items-center justify-center">
          <PhilosopherKingIcon
            state="thinking"
            className="size-7 text-accent-brand"
          />
        </div>
      </div>
      <p className="text-sm text-foreground/55">
        {isHe ? "טוען את התוכנית שלך…" : "Loading your plan…"}
      </p>
    </div>
  );
}
```

הערות-ביצוע מדויקות:
- `border-accent-brand/15` + `border-t-accent-brand` — הטבעת עכשיו אינדיגו (עמומה 15% + קצה מלא). Tailwind v4 יודע לגזור `/15` מטוקן `--color-accent-brand` (חשוף ב-globals:214). אם משום-מה opacity-modifier לא נתפס על הטוקן, החלף ל-`border-[color:var(--accent-brand)]/15` — אבל הצורה הרגילה אמורה לעבוד כי הטוקן ב-`@theme`.
- `text-accent-brand` על הכתר → `currentColor` בתוך ה-SVG נצבע אינדיגו. לא זהב. עומד ב"זהב רק למלך".
- `[animation-duration:900ms]` — סיבוב רגוע (ברירת-מחדל של Tailwind 1s בסדר גם; 900ms מעט חד יותר וחי). אופציונלי אבל מומלץ.
- `state="thinking"` מפעיל את `pk-king--thinking` הקיים — ספירת-הטוב המרכזית נושמת. אין קוד חדש ל-CSS.
- טקסט הועלה מ-`/40` ל-`/55` — קו-עיצובי.md:57 מגדיר `/50–/55` ל"משנה", ו-`/40` הוא לתוויות-מיקרו. משפט-טעינה שלם צריך להיות קריא → `/55`. הטריפל-נקודה `…` (תו יחיד) במקום `...`.
- הוסר `min-h-[40vh]` הישן; `page` עכשיו `min-h-[50vh]` (עקבי עם מסך-השגיאה ב-planner-content.tsx:72 שכבר `min-h-[50vh]`).
- `role="status"` + `aria-live="polite"` — נגישות; קורא-מסך מכריז "טוען".

## מה חסר
- **En-fallback ב-`useLocale`:** הקומפוננטה מניחה `locale === "he"` → אחרת אנגלית. תקין (אלה שתי השפות היחידות), אין חוב.
- **`aria-live="polite"` + `role="status"`:** תוספת-נגישות חדשה שלא הייתה בלואדר הקיים — שיפור אמיתי, מאושר. ודא ש-9 העמודים-השלמים לא כבר עטופים ב-`role="status"` הורה (double-announce). בדיקה מהירה: אף אחד מ-9 אתרי-עמוד-שלם לא מוסיף role — נקי.
- **אימות `prefers-reduced-motion` על הכתר:** המפרט מסתמך על guard-globals:679 שמכבה `animation-*`. אימתתי שה-guard קיים וגורף (`*`). אך `pk-orb-breathe` הוא היחיד שינוטרל; ה-`animate-spin` של הטבעת גם. במצב-סטטי נשאר: טבעת-אינדיגו חצי-שקופה + כתר-אינדיגו + טקסט. קריא. מאושר — רק ודא בפועל בשלב-4 (זה הבדיקה שהכי-קל לדלג עליה).
- **חסר: מה קורה ל-`className` prop כשמועבר יחד עם `variant`.** בקוד-החדש `cn(...)` ממזג נכון, אבל אף אתר-קריאה לא מעביר `className` כרגע (אימתתי — כולם `<ThemedLoader />` חשוף או `variant="inline"`). אין חוב, רק ציון שה-prop נשמר לתאימות-אחורה — טוב.
