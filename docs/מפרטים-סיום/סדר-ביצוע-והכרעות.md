## הוראות למבצע (אופוס 4.8)

- **קרא קודם:** המפרט + הביקורת-היריבה שבסופו. **בצע את תיקוני-הביקורת כחלק מהמפרט** — הם אינם אופציונליים. במחלוקת: הביקורת גוברת על המפרט, והקוד-החי גובר על שניהם.
- מפרט עם בנר-⛔ = תיעוד בלבד. ביצועו מחדש הוא רגרסיה על פרוד חי עם ~24 משתמשים.
- נוהל-הבית: `command git` (git מכוסה ב-alias); אין build+dev יחד; אימות בדפדפן דרך דמו (read-only; כתיבה עם משתמש-הבדיקה מ-.env.local ומחיקתו בסוף); `npx tsc --noEmit` + `npx vitest run` + `npm run lint` לפני כל קומיט; פריסה `npx vercel --prod --yes` ברקע; עדכון סטטוסים ב-docs/הערות-סיכום-אריאל.md אחרי כל אצווה; git push תמיד.
- מספרי-שורות במפרטים = עוגנים, לא אמת — התאם לפי תוכן (הקוד זז מאז).
- כשמשהו לא ברור: אל תנחש — רשום שאלה קצרה ב-docs/שאלות-לאריאל.md והמשך לפריט הבא.
