## ההחלטות (רשימה סגורה)

1. **"בלימוד" נגזר, לא נכתב.** לא מוסיפים שום כתיבה אוטומטית של IN_PROGRESS. התשובה ל-#22: קורס "הושלם" כשהסטודנט ענה עליו — ציון, עובר או פטור — והאפליקציה **שואלת** פעם בסמסטר, בטקס.
2. **טקס סוף-הסמסטר = כרטיס שקט בדשבורד** (data-card סטטי, צ'יפ-אייקון אינדיגו) — לא באנר ב-BannerStack (שמור לדמו+מילואים בלבד, קו-עיצובי §באנרים), לא אדום (זו לא חסימה). נפתח **14 יום אחרי סוף-ההוראה** (הציונים הראשונים מגיעים), נסגר לאותו סמסטר כשמסמנים "עודכן" / כשכל הקורסים קיבלו תשובה. **דילוג ("לא עכשיו") = שקט ל-7 ימים**, ואז חוזר בשקט.
3. **הסורק הוא נתיב-הזהב בשני מקומות**: ראש שלב-ההיסטוריה באונבורדינג + /record. המסלול הידני (צ'קבוקסים / GradeInput / AddCourse) נשאר גיבוי מלא, בלי שינוי התנהגות.
4. **הסבר "איפה משיגים את הגיליון" חי פעם אחת** — קומפוננטה אחת, מוצגת בסורק, באונבורדינג ובמדריך (עיקרון "כל עובדה חיה פעם אחת").
5. **רמת-אנגלית = שדה חדש `User.englishLevel`** שגובר על ציון-האמירנט (`resolveEnglishLevel`). נקלט משלושה מקומות: שורת-הרמה בגיליון (שיח, לא אוטומטי), Select באונבורדינג, Select בהגדרות. קורסי-רמה מהגיליון **לא** נוספים לרשומה — צ'יפ מסביר.
6. **כל החלה מהסורק מוצהרת מראש**: צ'יפ פר-שורה "יירשם כ...". רף אנגלית 70; "עובר"→COMPLETED בלי ציון; "פטור"→EXEMPT; "נכשל"→FAILED.
7. **מחיקת ציון לעולם לא משנה סטטוס** — בשני המסכים. במקום האוטומציה: טוסט עם כפתור-פעולה "סמן כ'בלימוד'". (מבטל את חוסר-העקביות ג' לעיל.)
8. **מעבר-סמסטר בפרופיל = שורה מפורשת בכרטיס-הטקס** ("עברתי לסמסטר הבא — עדכן"), לא אוטומציה. (נושא II ימחק את השאלה מההגדרות; זה הנתיב השיחתי.)
9. שורות ***-בלימוד מהגיליון: ב-/record — צ'יפ קיים (נשאר); באונבורדינג — מוצגות אך לא נטמעות ("ייכנס לתכנון בצעד הבא").
10. מיקום שנה·סמסטר לשורות-גיליון נגזר מדירוג כרונולוגי של כותרות-הסמסטר בגיליון עצמו (השנה הישנה ביותר = שנה א'), לא מניחוש לוח-שנה.

```ts
// שעון-הסמסטר — נגזרת יחידה מעל SEMESTER_TEACHING_DATES (מקור-האמת של נושא II).
// קובע האם אנחנו ב"חלון-ציונים" של סמסטר שהסתיים, ואיזה.
import { SEMESTER_TEACHING_DATES } from "@/lib/constants";

const GRADES_OPEN_DELAY_DAYS = 14;   // הציונים הראשונים ~שבועיים אחרי סוף ההוראה
const FALLBACK_WINDOW_DAYS = 134;    // כשאין תאריך לסמסטר הבא (סוף שנה"ל)

function addDays(d: Date, days: number): Date {
  const out = new Date(d);
  out.setDate(out.getDate() + days);
  return out;
}

export interface WrapTarget {
  semester: "FALL" | "SPRING";
  /** מפתח יציב לסמסטר, למשל "2026-SPRING" — לפי שנת תחילת-ההוראה. */
  key: string;
}

export function getWrapTarget(now: Date = new Date()): WrapTarget | null {
  const entries = [
    { semester: "FALL" as const, ...SEMESTER_TEACHING_DATES.FALL, next: SEMESTER_TEACHING_DATES.SPRING.start },
    { semester: "SPRING" as const, ...SEMESTER_TEACHING_DATES.SPRING, next: null as Date | null },
  ];
  for (const e of entries) {
    const open = addDays(e.end, GRADES_OPEN_DELAY_DAYS);
    const close = e.next ?? addDays(open, FALLBACK_WINDOW_DAYS);
    if (now >= open && now < close) {
      return { semester: e.semester, key: `${e.start.getFullYear()}-${e.semester}` };
    }
  }
  return null;
}

export const wrapStorageKey = (key: string) => `pakamon-wrap-${key}`;
```

```ts
export type ApplyDecision = { grade: number | null; status: "COMPLETED" | "FAILED" | "EXEMPT" };

/** מה בדיוק יירשם אם השורה תוחל — null = לא ניתנת להחלה. */
export function decideApplication(row: MatchedRow): ApplyDecision | null {
  if (!row.match) return null;
  if (row.grade != null) {
    const bar =
      row.match.courseType === "ENGLISH"
        ? ENGLISH_CONFIG.COURSE_PASSING_GRADE  // 70
        : CREDIT_REQUIREMENTS.PASSING_GRADE;   // 60

}
```

```ts
/** "2025/1" → {plannedYear, plannedSemester}. דירוג: השנה הישנה ביותר בגיליון = שנה א'. */
export function mapSheetSemesters(
  rows: ExtractedRow[],
): Map<string, { plannedYear: number; plannedSemester: "FALL" | "SPRING" | "SUMMER" }> {
  const keys = Array.from(
    new Set(rows.map((r) => r.semester).filter((s): s is string => !!s && /^\d{4}\/\d$/.test(s))),
  );
  const parsed = keys
    .map((k) => ({ k, y: Number(k.split("/")[0]), n: Number(k.split("/")[1]) }))
    .sort((a, b) => a.y - b.y || a.n - b.n);
  const years = Array.from(new Set(parsed.map((p) => p.y))).sort((a, b) => a - b);
  const map = new Map<string, { plannedYear: number; plannedSemester: "FALL" | "SPRING" | "SUMMER" }>();
  for (const p of parsed) {
    map.set(p.k, {
      plannedYear: Math.min(3, years.indexOf(p.y) + 1), // YEAR_CONFIG מכיר 1-3
      plannedSemester: p.n === 2 ? "SPRING" : p.n === 3 ? "SUMMER" : "FALL",
    });
  }
  return map;
}
```

```tsx
// שואלת → הסורק/העדכון-הידני עונים. כרטיס שקט, לא באנר, לא אדום.
import { useEffect, useState, useCallback } from "react";
import { useLocale } from "next-intl";
import { ScanLine, ChevronLeft } from "lucide-react";
import { Link } from "@/i18n/navigation";
import { toast } from "sonner";
import { api } from "@/lib/trpc/react";
import { getWrapTarget, wrapStorageKey } from "@/lib/semester-clock";
import { SEMESTER_CONFIG } from "@/lib/constants";
import { WhereIsMySheet } from "@/components/record/where-is-my-sheet";

const SNOOZE_DAYS = 7;

export function SemesterWrapCard({ profile, courses }: {
  profile: { currentYear: number; currentSemester: string } | undefined;
  courses: { plannedYear: number; plannedSemester: string; status: string; grade: number | null }[];
}) {
  const isHe = useLocale() === "he";
  const [visible, setVisible] = useState(false); // two-pass, כמו שאר הדשבורד
  const wrap = getWrapTarget();

  const pending = courses.filter(
    (uc) => profile && uc.plannedYear === profile.currentYear && wrap &&
      uc.plannedSemester === wrap.semester &&
      (uc.status === "PLANNED" || uc.status === "IN_PROGRESS"),
  );

  useEffect(() => {
    if (!wrap || !profile || pending.length === 0) return;
    const stored = localStorage.getItem(wrapStorageKey(wrap.key));
    if (stored === "done") return;
    if (stored && Date.now() - new Date(stored).getTime() < SNOOZE_DAYS * 86_400_000) return;
    setVisible(true);
  }, [wrap?.key, profile, pending.length]);

  const snooze = useCallback(() => {
    if (wrap) localStorage.setItem(wrapStorageKey(wrap.key), new Date().toISOString());
    setVisible(false);
  }, [wrap]);
  const markDone = useCallback(() => {
    if (wrap) localStorage.setItem(wrapStorageKey(wrap.key), "done");
    setVisible(false);
  }, [wrap]);

  const updateProfile = api.user.updateProfile.useMutation({
    onSuccess: () => { toast.success(isHe ? "הפרופיל עודכן לסמסטר הבא" : "Profile moved to the next semester"); markDone(); },
    onError: () => toast.error(isHe ? "העדכון נכשל — אפשר לעדכן בהגדרות" : "Update failed — try settings"),
  });

  if (!visible || !wrap || !profile) return null;
  const semName = isHe ? SEMESTER_CONFIG[wrap.semester].nameHe : SEMESTER_CONFIG[wrap.semester].nameEn;
  const stillOnEnded = profile.currentSemester === wrap.semester;

  return (
    <div className="data-card p-4">
      <div className="flex flex-wrap items-center gap-3">
        <div className="flex size-10 shrink-0 items-center justify-center rounded-xl bg-accent-brand-muted text-accent-brand">
          <ScanLine className="size-5" />
        </div>
        <div className="min-w-0 flex-1">
          <p className="text-sm font-semibold text-foreground/85">
            {isHe ? `${semName} הסתיים — יש כבר ציונים?` : `${semName} is over — got grades yet?`}
          </p>
          <p className="text-xs text-foreground/50">
            {isHe
              ? `${pending.length} קורסים מהסמסטר מחכים לעדכון. סריקה אחת של הגיליון סוגרת הכול.`
              : `${pending.length} courses from the semester await an update. One sheet scan closes them all.`}
          </p>
        </div>
        <div className="flex shrink-0 items-center gap-2">
          <Link href="/record?scan=1"
            className="inline-flex items-center gap-1.5 rounded-lg bg-accent-brand px-3 py-2 text-sm font-semibold text-accent-brand-fg transition-colors hover:bg-accent-brand-hover">
            <ScanLine className="size-4" />{isHe ? "לסריקת הגיליון" : "Scan the sheet"}
          </Link>
          <Link href="/record" className="rounded-lg px-2.5 py-2 text-xs font-medium text-foreground/55 hover:bg-foreground/5">
            {isHe ? "עדכון ידני" : "Manual"}
          </Link>
          <button type="button" onClick={snooze} className="rounded-lg px-2.5 py-2 text-xs text-foreground/40 hover:bg-foreground/5">
            {isHe ? "לא עכשיו" : "Not now"}
          </button>
        </div>
      </div>
      <div className="mt-2"><WhereIsMySheet /></div>
      {stillOnEnded && (
        <div className="mt-2 flex items-center gap-2 border-t border-border/40 pt-2 text-xs text-foreground/50">
          {isHe ? "סיימת לעדכן?" : "Done updating?"}
          <button type="button"
            onClick={() => updateProfile.mutate(
              wrap.semester === "FALL"
                ? { currentSemester: "SPRING" }
                : { currentSemester: "FALL", currentYear: Math.min(profile.currentYear + 1, 4) })}
            className="inline-flex items-center gap-1 font-medium text-accent-brand hover:text-accent-brand-hover">
            {isHe ? "עברתי לסמסטר הבא — עדכן פרופיל" : "Moved on — update profile"}
            <ChevronLeft className="size-3 rtl:rotate-0 ltr:rotate-180" />
          </button>
        </div>
      )}
    </div>
  );
}
```

## מה חסר

שלושה דברים שהמפרט לא נוגע בהם ושייכים לליבת #30/#22: (א) **ההזנה הידנית עצמה היא האוטומציה השקטה שנשארה** — GradeInput ב-/record כותב `"COMPLETED"` ללא-תנאי (academic-record-content.tsx:139) וב-/graduation כנ"ל (grade-calculator-content.tsx:106-110): הקלדת 45 ידנית ⇒ "הושלם", בעוד אותו ציון מהסורק ⇒ "נכשל". טבלת-האוטומציות מכריזה "כולן" אבל שורה זו חסרה בה; לכל הפחות לרשום אותה כהחלטה מודעת-מחוץ-לתכולה, אחרת אריאל יגלה את חוסר-העקביות ביום הראשון של חלון-הציונים. (ב) **סטודנט לא-סדיר** — pending מסונן על `plannedYear === currentYear`, כך שקורס-השלמה משנה א' שנלמד עכשיו בשנה ב' לא ייספר בטקס ולא יציף את הכרטיס; שווה משפט אחד שמקבל זאת במודע. (ג) **תצוגת הרמה שנקבעה** — אחרי שנשמר `englishLevel`, אין במפרט שום מקום שבו המשתמש רואה בהגדרות שהרמה-הידנית היא זו שגוברת על ציון-האמירנט הקיים (רק כיתוב-משנה כללי); כשהשניים סותרים זה בדיוק "שיח במקום שקט". מעבר לכך — זחילת-scope מתונה ומוצדקת ברובה: היחידים שאפשר לגזור בלי לפגוע בהערות הם צעד 2ג/מיקום-סמסטרים (יש fallback ממילא) וכפתור 5.5 — שתיהן נגזרות-נוחות, לא דרישות של אריאל. סיכוני-הרגרסיה על הפרוד מנוהלים נכון (מיגרציה אדיטיבית nullable, שינוי-חתימה עם grep-קוראים שאומת — route.ts:137 והבדיקות הם באמת הקוראים היחידים). אחרי סגירת ליקויים 1-3, המפרט ראוי לביצוע ע"י Opus בלי שאלות.
